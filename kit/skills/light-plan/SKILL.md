# Plan

For the request folder named in the request (a `specs/NNN-slug` path; if none is named, use the active request in `specs/*/status.md`): run the missing discovery and design steps of its workflow, then act as **light-tech-lead** to write `40-plan.md`. When the plan was already agreed in a discussion or plan-mode session, transcribe it task by task (`light-conversation-capture`), then check it against the code. Commit it with the `light-commit` skill. Do not implement.
